RAP SHEET - quick start (Windows 10/11, 64-bit)

1. Unzip this folder anywhere (e.g. Documents). Double-click "Rap Sheet.exe".
   If Windows SmartScreen warns, choose More info > Run anyway (the app is unsigned).
2. Follow the 5-step setup. It asks for:
   - Your Streamlabs replay folder (Streamlabs: Settings > Output > Recording Path).
   - Your incident key. In Streamlabs, bind "Save Replay" to a key (e.g. F9),
     then press the same key in Rap Sheet. One press = clip saved + incident marked.
   - Optional: drag a box around your kill feed so it can suggest player names.
3. Play in BORDERLESS WINDOWED mode (exclusive fullscreen can capture black).
4. After a match, open Rap Sheet > Incidents > pick the name > Make report.

What it does NOT do: it never touches the game, never sends keys, never uploads
anything. Everything stays on your PC (Settings > Open data folder).
It reads the screen the same way OBS does. Anti-cheat could in theory dislike any
global key listener, so if a game ever warns you, turn off "Hotkey" use and use
the on-screen "Mark incident now" button instead.
