How to use Rap Sheet

      
Quick start. Everything stays on your PC.

      

        
1. Set up once

        
    
          
  • Settings: check your hotkey (default F5), your game (choose Other and type a name for new games), and the game window from the dropdown.
    • 
          
  • Turn on Recording to save a video of each incident, and Screen reading to suggest player names.
    • 
          
  • Click Move / resize area and drag the box over the part of the screen where names show (kill feed, nameplates, chat). Press Enter to save. You can move it any time, and it is remembered per game window.
    • 
        

        
2. In game

        
    
          
  • See something suspicious? Press your hotkey. This marks the moment and starts recording and reading names.
    • 
          
  • Press it again when it is over. It also stops by itself after the time limit in Settings.
    • 
          
  • Keep playing. You do not need to alt-tab.
    • 
        

        
3. After the match

        
    
          
  • Incidents tab: each mark shows the recording and any names it read. Tap the right name, then press Make report.
    • 
          
  • Report tab: pick the suspect name, tick what they did, add a short description. Use Choose file to attach a clip or screenshot, or Drag out to drop it into Discord or a report form.
    • 
          
  • Copy the report text and send it to the game's report channel. The tab shows where to send it for each game.
    • 
          
  • Repeat offenders tab: shows players you have reported more than once.
    • 
        

        
Tips

        
    
          
  • Run "Test reading now" in Settings with the game open to check the name area is right.
    • 
          
  • If the game stutters, turn Recording quality down to 720p or switch off Screen reading.
    • 
          
  • Something wrong? Settings, Copy beta feedback, then paste it to whoever sent you the beta.
    • 
        

        
Rap Sheet only reads your own screen and does not touch the game. Some anti-cheat systems may still object to screen capture or global hotkeys, so try casual play first. By default Rap Sheet uses a normal Windows hotkey and does not watch your keyboard.

      

    


    

      
Settings


      

        
Incident hotkey

        
Press this key in game to start an incident, and again to stop. Default is F5. Rap Sheet never presses keys for you.

        
not set

        
        
      


      

        
Recording

        
Rap Sheet can record the game window itself, so you get video without relying on Streamlabs. Press your incident key to start recording and press it again to stop. It has no sound, and saves a video file you can drag into Discord or most upload pages. It cannot include what happened before the first press.

        
        
        
        
        

        
        

        

      


      

        
Replay clips

        
The folder where Streamlabs saves replays (Settings > Output > Recording Path). Rap Sheet links each new clip to your incident.

        

        

        
      


      

        
Screen reading

        
Reads one small area of your screen (the kill feed or name tags) and remembers names that keep appearing, so the right name is one tap away. By default it only reads between two presses of your incident key. It reads only the game window's own picture, so Discord, overlays and anything else on your desktop are never seen. It reads pixels the way OBS does and never touches the game itself. Needs the game in borderless windowed mode and not minimized.
